Step 1: Get path of 'mods' folder

  1. Open Windows search
  2. Search for '%appdata%
  3. Go to .minecraft folder
  4. Select 'mods' folder (but do not go into it)
  5. At the top of file explorer, there should be an option to 'copy path' (Windows 11 and 10 are a bit different)

Step 2: Pick location of shortcut

Anywhere is fine, Desktop is usually easiest

Step 3: Create shortcut

  1. Right click anywhere in the folder (or just the desktop)
  2. Select New > Shortcut
  3. Paste in the path for the 'mods' folder that was copied earlier (from Step 1)
  4. Name the shortcut (mods, minecraftmods, etc)

Now when copying mods into the mods folder, just simply use the shortcut to get to the 'mods' folder
