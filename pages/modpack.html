Step 3: Copy Mods to the 'mods' folder in .minecraft

The '.minecraft' folder is found in the AppData folder (Click here for a quide to setup a shortcut)

  1. Open Windows search
  2. Search for '%appdata%
  3. Go to Roaming/.minecraft/mods
  4. Copy all files from the zip file into the 'mods' folder
